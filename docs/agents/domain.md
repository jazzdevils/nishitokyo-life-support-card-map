# Domain Documentation

This project uses a **single-context** layout for domain documentation.

## Structure

- `CONTEXT.md` at the repo root provides overall project context
- `docs/adr/` contains Architecture Decision Records (ADRs)

## Consumer Rules

When working with this project:
1. Read `CONTEXT.md` first to understand the domain
2. Check `docs/adr/` for architectural decisions
3. Follow the vocabulary and terminology established in these documents
