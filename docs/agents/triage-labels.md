# Triage Labels

Using default label vocabulary:

- `needs-triage` — Initial state for all new issues
- `needs-info` — Waiting for additional information from the reporter
- `ready-for-agent` — Ready for AI agent to work on
- `ready-for-human` — Needs human review or intervention
- `wontfix` — Will not be fixed by design

These labels are used by the `triage` skill to categorize and manage issues.
